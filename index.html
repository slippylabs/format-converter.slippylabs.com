DATA FORMAT CONVERTER

Paste in any of the five formats and read it back out as any other. The format of what you paste is detected automatically, and anything a conversion has to drop is listed rather than silently lost.

What this conversion cannot carry across

    Each parser covers the part of its format that configuration files actually use. YAML: block and flow collections, all five scalar styles, comments, multi-document input (first document only) — but not anchors, aliases or custom tags. TOML: tables, arrays of tables, inline tables, all string forms and dotted keys — dates are read as text. CSV: RFC 4180 quoting, with the first row as the header. XML: elements, attributes and text; comments, namespaces prefixes and processing instructions are dropped.
